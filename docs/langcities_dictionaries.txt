when calculated changes, mark field as dirty
if formula changes but calculated does not, retain current field status
value = value ?? calculated <- formula

automatic updates are triggered when value changes, not when calculated changes
if automatic update happens, save original version of entry to job, when job finishes, if version has not changed, then save calculated, increment version and mark dirty
if manual update happens, save calculated and increment version, mark clean
accept calculated value updates value and marks clean, triggers updates to children

for example:
    :mt.136.ipa.formula = $sc.ot2mt(:ot.123.ipa)
    :ot.123.ipa.value = '/new/'
    new job created for :mt.136.ipa, save current version number
    if :mt.136.ipa.version has not changed,
    update :mt.136.ipa.calculated
    :mt.136.ipa.dirty = true
